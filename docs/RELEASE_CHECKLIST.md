# Google Play Release Checklist

- Install Godot 4 stable and Android export templates.
- Install Android SDK, platform tools, build tools, and JDK 17; configure Godot editor paths.
- Replace provisional package identifier with the approved reverse-DNS identifier.
- Create a production keystore outside the repository and configure an export preset without committing secrets.
- Validate portrait safe areas, lifecycle save/resume, audio, haptics and performance on a physical Android device.
- Prepare 512px icon, feature graphic, screenshots, content rating, Data Safety answers and privacy policy URL.
- Run internal, closed and production tracks. Do not upload or publish without explicit authorization.
